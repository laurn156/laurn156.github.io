# Lauren Nunez

Source for my personal website: **[laurn156.github.io](https://laurn156.github.io)**

I'm a Mechatronics Engineering student at Kennesaw State University working on robotics and AI. The site covers my projects and involvement.

## Structure

- `_pages/`: Home (`about.md`), Projects, and Involvement pages
- `_portfolio/`: one Markdown file per project
- `images/`: project photos and site icons
- `_config.yml`: site settings and profile info

The site is built with Jekyll and hosted on GitHub Pages. It uses the [Academic Pages](https://github.com/academicpages/academicpages.github.io) theme (MIT license, see `LICENSE`).
